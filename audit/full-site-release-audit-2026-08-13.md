## 4. SEO、AEO 与 GEO 审查

### SEO

产品、文章与区域页采用自指 canonical、语言 alternates、描述性标题及 R2 语义图片 URL。公开图片使用 `images.houseplus-ch.com/media/{semantic-slug}/`；图片站点地图与主站点地图均已部署。商品页采用询盘型 `ContactAction`，避免把未确认商业条件写成伪 `Offer`。

### AEO

动态文章使用 `BlogPosting`；具有页面可见问答的文章配置 `FAQPage`。产品目录使用 `CollectionPage`、`ItemList` 与面包屑；产品页提供面向采购询盘的结构化联系动作。此设计使回答引擎能够识别产品、内容主体、实体关系与询盘路径，而不会把价格或库存推断为公开承诺。

### GEO

图片媒体库已经保存英文 Alt Text、SEO 标题、GEO 描述、语义 URL 与页面关系；R2 Worker 可进行 WebP 协商，并使用 `Vary: Accept`。`llms.txt` 已包含可引用的内容与图片规则，页脚 `Organization` 与 `Logo` 提供统一品牌实体锚点。

### 本轮 Schema 治理

`schema-generator.ts` 已移除未核验的 `foundingDate`、员工数量、奖项、价格范围和营业时间等字段；产品的 MOQ、交期、认证、工厂规模和出口国家属性在完成“产品 × 目的地”的资料核验流程前不再发布。这样优先保证结构化数据与页面可证明事实一致。

## 7. 建议的日常运营流程

1. **新图片：** 在 `/admin/media` 上传或关联 R2 资源，填写准确英文 Alt Text、SEO 标题与 GEO 描述，再关联规范页面 URL 并批准。
2. **新产品/文章：** 先完成英语源内容与事实资料，再在集中本地化层补齐 ES/DE/FR/AR；不能以英文正文回退替代正式翻译。
3. **新发布：** 本地运行生产构建，检查 canonical、`hreflang`、结构化数据与图片 URL 后再部署。
4. **修改后通知：** 在 `/admin/indexnow` 选择对应平台并提交线上站点地图；只在实质性修订或投递失败时启用强制重提。
5. **每季度复核：** 导出媒体、Schema 与 Search Console 状态，核验所有公开的商业、合规和联系信息。

## 8. 最终判断

本次发布已满足当前项目的核心目标：**五语内容可索引、R2 图片治理落地、B2B 询盘定位明确、关键商业信息不再伪造或过度承诺、Schema 更接近可证明事实，并且新的线上站点地图已成功通知搜索平台。** 后续最有价值的投入是建立可审计的事实来源与合规证据台账，并将剩余共享 UI 文案纳入统一五语词典。
