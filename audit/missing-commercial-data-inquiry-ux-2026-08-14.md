# 缺固定商业资料产品的询盘体验验收

**日期：** 2026-08-14

## 范围

本次检查覆盖 18 个未配置固定 MOQ、交期、保修或认证资料的产品，以及 EN、ES、DE、FR、AR 五种语言的产品页和 Contact 页。

## 修复

1. 产品页两个报价入口均将产品名称和 SKU 作为查询参数传入联系页。
2. 非英语 Contact 页面不再被通用基础页面重写替代，保留完整的真实询盘表单。
3. 表单实现五语言字段、占位文本、提交状态、速率限制提示、成功反馈和错误反馈，并使用无障碍状态区域。
4. 询盘页在窄屏下使用单列字段，在中等及以上屏幕使用双列字段；RTL 页面以阿拉伯语文本和方向显示。

## 生产验证

| 检查项 | 结果 |
|---|---:|
| 缺资料产品的报价 CTA | 18 产品 × 5 语言 = 90/90 均包含产品上下文链接 |
| 五语言 Contact 页真实表单 | 5/5 均包含表单、产品字段和必填消息字段 |
| 阿拉伯语产品预填验证 | 通过，产品名称与 SKU 已进入表单产品字段 |
| 真实提交 | 未执行，避免向生产销售邮箱发送测试询盘 |

真实 API 已保留现有服务端字段验证和每 IP 每小时 5 次速率限制。后续需要邮件送达测试时，应在用户确认后使用专门测试邮箱和明确的测试标记。
