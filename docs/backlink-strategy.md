## 毒性链接监控

### 月度检查流程
1. 登录 Google Search Console → 链接报告
2. 导出最新外链列表
3. 使用 Semrush Backlink Audit 检查毒性评分
4. 毒性评分 > 50 的链接加入 Disavow 文件
5. 提交 Disavow 文件至 Google Disavow Tool

### 注意事项
- 外贸行业偶有恶意刷垃圾外链攻击
- 发现异常外链激增时立即检查
- 不要 disavow 低质量但非恶意的链接
- 保留 disavow 文件历史记录
