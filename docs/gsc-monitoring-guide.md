# Google Search Console (GSC) 监控配置指南

## 一、GSC 账户设置

### 1.1 添加网站属性

1. 访问 [Google Search Console](https://search.google.com/search-console)
2. 点击 **"添加资源"**
3. 选择 **"网域"** 输入：`houseplus-ch.com`
   - 选择网域而非网址前缀，可同时覆盖 http/https 和 www/non-www
4. 完成域验证（DNS TXT 记录方式最稳定）

### 1.2 DNS 验证步骤

登录域名管理面板（如 Alibaba Cloud/Cloudflare），添加 TXT 记录：

```
主机记录: @
记录类型: TXT
记录值:   google-site-verification=XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

> GSC 会提供具体的验证值，替换上面的 `XXXX...` 部分。DNS 传播通常需 10 分钟 - 48 小时。

### 1.3 同时添加所有变体（备用）

| 资源类型 | 网址 |
|----------|------|
| 网域（主） | `houseplus-ch.com` |
| 网址前缀 | `https://houseplus-ch.com` |
| 网址前缀 | `https://www.houseplus-ch.com` |

## 二、站点地图提交

### 2.1 提交现有站点地图

1. GSC 左侧菜单 → **站点地图**
2. 输入站点地图 URL（相对路径）

```
sitemap.xml
```

3. 点击 **"提交"**，等待 Google 索引

### 2.2 检查站点地图状态

提交后在 GSC 中监控以下指标：

| 指标 | 健康值 | 告警阈值 |
|------|--------|----------|
| 已发现的网址数 | 与产品页总数匹配 | 持续下降 |
| 已索引的网址数 | >80% 发现数 | <50% |
| 索引覆盖率 | >90% | <70% |
| 上次读取时间 | <7 天 | >14 天 |

### 2.3 图片站点地图（配合图片优化）

在产品图片优化完成后，额外提交图片站点地图：

```
image-sitemap.xml
```

## 三、核心监控指标设置

### 3.1 搜索效果报告 — 关键维度

在 GSC **搜索效果** 报告中，按以下维度分组监控：

| 维度 | 用途 | 关注指标 |
|------|------|----------|
| **查询（搜索词）** | 发现用户用什么词找到网站 | 展示次数、点击次数、CTR |
| **网页** | 识别表现最好/最差的页面 | 点击次数、平均排名 |
| **国家/地区** | 了解流量地域分布 | 展示次数、点击次数 |
| **设备** | 桌面/移动端表现差异 | CTR、排名 |
| **搜索外观** | 富摘要展示情况 | 展示次数（按类型） |

### 3.2 关键搜索词分组

#### 品牌词组
```
houseplus
houseplus solar
houseplus-ch
```
- **目标 CTR**: >30%（品牌词应保持高点击率）
- **告警**: CTR 低于 20% 说明品牌知名度或搜索结果吸引力不足

#### 产品核心词组
```
solar panel manufacturer
solar inverter wholesale
home appliance supplier china
solar energy system OEM
```
- **目标排名**: 前 20 名（逐步提升至前 10）
- **告警**: 排名持续下降超过 5 个位次

#### 长尾关键词组
```
500w monocrystalline solar panel wholesale
ce certified solar panel manufacturer china
moq 100 solar panel supplier
off grid solar system for home
```
- **目标**: 展示次数持续增长
- **关注**: 新出现的搜索词（市场新需求信号）

### 3.3 核心页面分组

| 页面类型 | 关键页面 URL 模式 | 核心指标 |
|----------|-------------------|----------|
| 首页 | `/` 或 `/en` | 展示次数、品牌词 CTR |
| 产品列表 | `/en/products` | 分类词排名、点击数 |
| 产品详情 | `/en/products/[slug]` | 产品词排名、转化率 |
| 博客/资源 | `/en/blog/[slug]` | 长尾词展示次数 |
| 关于我们 | `/en/about` | 品牌信任词排名 |

### 3.4 低 CTR 页面优化（CTR < 5% 告警）

当 GSC 搜索效果报告中发现 **CTR 低于 5%** 的页面时，按以下流程优化：

#### 告警条件
- 展示次数 > 100 且 CTR < 5% 的页面
- 排名在前 20 名但 CTR < 3% 的页面

#### 优化步骤

1. **分析当前 Title 和 Meta Description**
   - 在 GSC → 搜索效果 → 点击页面 URL → 查看展示该 URL 的搜索查询
   - 检查 Title 是否包含用户搜索的关键词
   - 检查 Meta Description 是否在 150-155 字符以内且包含行动号召

2. **Title 优化**
   - 将核心关键词前移至 Title 前 30 个字符
   - 添加转化关键词：`Wholesale`、`Manufacturer`、`OEM/ODM`、`CE Certified`
   - 保持 Title 在 50-60 字符之间
   - A/B 测试：每次只修改一个变量，观察 2-4 周后比较 CTR 变化

3. **Meta Description 优化**
   - 确保包含搜索意图关键词
   - 添加行动号召：`Get a quote`、`Request wholesale pricing`、`Download specs`
   - 突出差异化：`MOQ 100 pcs`、`25-year warranty`、`53+ countries served`
   - 确保字符数在 150-155 之间（超出会被截断）

4. **富摘要增强**
   - 检查页面是否已输出 Product Schema、FAQ Schema、Breadcrumb Schema
   - 在 GSC → 增强功能中确认结构化数据无错误
   - 添加 Rating/Review Schema 以显示星级评分（提升 CTR 15-30%）

5. **跟踪与迭代**
   - 修改后在 GSC 中使用 URL 检查工具请求重新抓取
   - 2-4 周后重新检查 CTR 数据
   - 如果 CTR 仍 < 5%，考虑更大幅度修改 Title 或添加 FAQ 模块

#### CTR 优化检查清单

| 检查项 | 状态 |
|--------|------|
| Title 包含目标关键词 | ☐ |
| Title 在 50-60 字符之间 | ☐ |
| Meta Description 包含行动号召 | ☐ |
| Meta Description 在 150-155 字符之间 | ☐ |
| 页面输出结构化数据（Product/FAQ/Breadcrumb） | ☐ |
| 已请求 GSC 重新抓取 | ☐ |
| 2-4 周后复查 CTR 数据 | ☐ |

## 四、索引覆盖率监控

### 4.1 常见索引问题处理

在 GSC → **索引** → **网页** 中关注以下状态：

| 状态 | 含义 | 处理方式 |
|------|------|----------|
| ✅ 已编入索引 | 正常，无需处理 | — |
| ⚠️ 已发现 - 尚未编入索引 | Google 已发现但还没索引 | 等待 1-2 周；可通过 GSC "请求编入索引" 加速 |
| ❌ 已排除 - 标记为 'noindex' | 页面包含 noindex meta 标签 | 检查页面 meta 标签，移除不必要的 noindex |
| ❌ 已排除 - 被 robots.txt 屏蔽 | robots.txt 阻止了爬取 | 更新 robots.txt（已完成优化） |
| ❌ 已排除 - 重复网页（规范网页） | 重复内容被合并 | 确保 canonical URL 正确设置 |
| ❌ 已排除 - 检测到 '404' | 页面不存在 | 检查死链，设置 301 重定向或返回正确 404 |

### 4.2 定期检查频率

| 检查项 | 频率 | 负责人 |
|--------|------|--------|
| 索引覆盖率 | 每周 | SEO 管理员 |
| 新页面索引状态 | 新页面发布后 3 天 | 内容团队 |
| 404 错误页面 | 每周 | 技术团队 |
| Schema 错误 | 每月 | 技术团队 |

## 五、Core Web Vitals 监控

### 5.1 关键指标

在 GSC → **体验** → **核心网页指标** 中监控：

| 指标 | 含义 | 良好值 | 需改进 | 差 |
|------|------|--------|--------|-----|
| **LCP** | 最大内容渲染时间 | ≤2.5s | 2.5-4.0s | >4.0s |
| **INP** | 交互到下一次绘制延迟 | ≤200ms | 200-500ms | >500ms |
| **CLS** | 累积布局偏移 | ≤0.1 | 0.1-0.25 | >0.25 |

### 5.2 URL 检查工具

对每个关键页面使用 GSC 的 **URL 检查** 工具：

1. 输入完整 URL（如 `https://houseplus-ch.com/en/products/solar-panel-hp500w`）
2. 点击 **"测试实际网址"**
3. 查看：
   - 是否已编入索引
   - Google 抓取的页面标题和描述
   - 结构化数据检测结果
   - Core Web Vitals 实测数据
   - 已安装的 AMP 状态（如适用）
   - 网页的已展开规范网址

## 六、结构化数据监控

### 6.1 增强功能报告

GSC → **增强功能** → 监控以下 Schema 类型的状态：

| Schema 类型 | 对应页面 | 检查频率 |
|-------------|----------|----------|
| `Product` | 产品详情页 | 每月 |
| `FAQPage` | 产品详情页 FAQ | 每月 |
| `BreadcrumbList` | 所有页面 | 每月 |
| `Organization` | 关于我们页 | 季度 |
| `WebSite` | 首页（搜索框） | 季度 |

### 6.2 常见 Schema 错误修复

| 错误类型 | 原因 | 修复 |
|----------|------|------|
| 缺少必填字段 | Product 缺少 name 或 offers | 补全 Product Schema 字段 |
| 值不符合规范 | price 非数字格式 | 确保 price 为纯数字 |
| 重复项 | 同一页面多个 Product 标记 | 每页只保留一个主要 Product |
| 无法解析 | JSON-LD 格式错误 | 使用 [Schema Markup Validator](https://validator.schema.org) 验证 |

## 七、手动操作指南

### 7.1 请求编入索引

当发布新页面或更新重要页面后：

1. GSC 顶部搜索框输入完整 URL
2. 点击 **"请求编入索引"**
3. 等待 Google 处理（通常 1-5 天）

### 7.2 移除过时内容

当产品下架或页面删除时：

1. **首选**: 返回 404 状态码（让 Google 自然移除）
2. **次选**: 301 重定向到相关产品页
3. **紧急**: GSC → **移除** → 临时移除旧 URL（仅限紧急情况）

### 7.3 导出数据报告

定期导出数据用于分析：

| 报告 | 导出频率 | 用途 |
|------|----------|------|
| 搜索效果（按查询） | 每月 | SEO 策略调整依据 |
| 搜索效果（按网页） | 每月 | 内容优化优先级 |
| 索引覆盖率 | 每月 | 技术健康度追踪 |
| Core Web Vitals | 每月 | 性能优化评估 |
| 外链报告 | 每季度 | 外链建设效果追踪 |
