# HousePlus 全站图片 SEO 与生成式引擎 GEO 优化记录

## 优化目标

本次优化将 **SEO** 定义为搜索引擎优化，将 **GEO** 定义为生成式引擎优化。实现重点是让图片能够被传统搜索、图片搜索、社交分享解析器和生成式问答引擎准确理解、抓取与引用，同时避免无依据的产品、价格、认证或交期推断。

| 优化层 | 已完成内容 | 覆盖结果 |
| --- | --- | --- |
| 品牌可识别性 | 放大首页、品牌页和联系页 Logo 卡片，并增加更清晰的品牌标题属性 | 三个关键转化页面已更新 |
| 图片语义 | 统一为原生图片保留描述性 `alt`，补充对应 `title` 和 `decoding="async"` | 66/66 原生图片具备 alt、title 和异步解码属性 |
| 社交图片 | 使用绝对图片 URL、1200×675 预览尺寸、描述性图片替代文本和 `metadataBase` | Open Graph 与 Twitter 图片输出统一 |
| 图片站点地图 | 重建 `/image-sitemap.xml`，包含产品图、25 篇文章的独立封面和关键页面图 | 102 个带标题与说明的图片条目 |
| 结构化图片实体 | 为产品和文章的 `ImageObject` 加入标题、描述、尺寸和内容地点信息 | Product 与 BlogPosting 图片实体已增强 |
| 生成式引擎入口 | 重写 `/llms.txt`，提供统一实体定义、可引用事实、核心页面、引用边界和联系人信息 | 生成式引擎可读取的规范内容入口已就绪 |
| AI 抓取发现 | 更新 `/robots.txt`，明确允许相关生成式爬虫发现新闻、产品、`llms.txt` 与图片站点地图 | GPTBot、ChatGPT-User、Claude-Web、PerplexityBot 等入口明确 |

## 生成式引擎引用规范

`/llms.txt` 将 HousePlus 定义为位于中国广东中山的 B2B 制造商、OEM/ODM 合作伙伴与批发供应商，主营太阳能系统、家电与 3C 电子产品。该入口同时规定：引用时应使用对应的规范页面 URL；不要从一般介绍页推断库存、价格、交期、认证覆盖或定制可行性；应以具体产品页和询盘页面作为商业信息的确认来源。

## 验证结果

生产构建已成功通过。最终本地生产预览已确认：新版 `llms.txt`、`robots.txt`、图片站点地图和首页的社交图片与结构化元数据入口均可访问；图片站点地图包含 102 个图片条目；首页放大后的 Logo 保持了与轮播、标题和行动按钮的视觉平衡。

## 上线后建议

部署后，应在 Google Search Console 和 Bing Webmaster Tools 重新提交主站点地图及图片站点地图，并使用社交分享调试工具刷新首页和文章页的 Open Graph 缓存。生成式引擎的抓取与引用效果取决于各平台的独立索引周期，技术优化可提升发现与理解能力，但不能保证任何特定模型或产品立即引用网站内容。
