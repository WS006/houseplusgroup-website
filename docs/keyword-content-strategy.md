## 内容规范

### 文章结构模板
```
H1: 文章标题（含目标关键词）
  导语段落（100字内，含目标关键词）

H2: 核心问题概述
  正文段落（300-500字）

H2: 技术分析/参数对比
  H3: 参数A
  H3: 参数B
  H3: 参数C
  对比表格

H2: 实际应用建议
  正文 + 要点列表

H2: 采购建议
  H3: 如何选择
  H3: 价格参考
  H3: 认证要求

H2: FAQ（3-5个常见问题）
  Q&A 格式 + FAQPage Schema

H2: 总结
  关键要点 + CTA
```

### SEO 要求
- 每篇文章 1,500-2,500 字
- 标题含目标关键词
- Meta Description 含目标关键词 + CTA
- 首段 100 字内出现关键词
- 自然融入 3-5 个 LSI 关键词
- 至少 1 个对比表格
- 至少 3 张图片（含 alt 文本）
- 内链 2-3 个相关产品页
- 外链 1-2 个权威来源（.gov/.edu/行业权威站）
- FAQPage Schema 结构化数据

### 多语言版本
优先翻译为 5 种语言：
1. English (en) — 主版本
2. Spanish (es) — 拉美市场
3. German (de) — 欧洲市场
4. French (fr) — 非洲法语区
5. Arabic (ar) — 中东市场
