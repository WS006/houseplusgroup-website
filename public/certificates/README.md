# Certificate Files Directory

This directory should contain downloadable PDF certificates referenced by the CertificationDisplay component.

## Required Files

Upload the following certificate PDFs to this directory:

1. `houseplus-ce-certificate.pdf` — CE Certification
2. `houseplus-fcc-certificate.pdf` — FCC Certification
3. `houseplus-rohs-certificate.pdf` — RoHS Compliance
4. `houseplus-iso9001-certificate.pdf` — ISO 9001:2015
5. `houseplus-iec61215-certificate.pdf` — IEC 61215 Solar Panel Design Qualification
6. `houseplus-iec61730-certificate.pdf` — IEC 61730 Solar Panel Safety Qualification

## SEO Impact

Providing downloadable certificate PDFs:
- Builds buyer trust (E-E-A-T signals)
- Improves conversion rate for wholesale buyers
- Adds crawlable PDF content for search engines
- Supports customs clearance documentation

## Instructions

1. Scan or export original certificate documents as PDF
2. Name files exactly as listed above
3. Upload to this directory (`/public/certificates/`)
4. Verify download links work on the live site
5. Ensure PDFs are text-searchable (not scanned images only)
